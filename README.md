# Atualizações do Prontuário Eletrônico

Este repositório guarda apenas o arquivo `versao.json`, usado pelo próprio aplicativo
para checar se existe uma atualização disponível (botão "Verificar atualização" dentro do app).

Nenhum dado de paciente ou informação do consultório fica aqui — só o número da versão mais
recente e um link de download dos arquivos atualizados.
