# ProntoMed — atualizações

Este repositório guarda apenas:

- o arquivo `versao.json`, lido pelo próprio aplicativo para avisar quando há versão nova
  (botão "Verificar atualização");
- o instalador do Windows de cada versão, na aba **Releases**.

Nenhum dado de paciente, código-fonte ou informação de consultório fica aqui.
O instalador só abre o aplicativo mediante uma chave de licença emitida pelo fornecedor.
